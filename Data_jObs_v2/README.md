# Data Jobs Dashboard 2.0 | Power BI

## Introduction

Exploring the data job market can be challenging when information about salaries, job titles, and in-demand skills is spread across different sources.

I built this **Data Jobs Dashboard 2.0** using Power BI to make it easier to explore the data job market. By analyzing job postings data, I aimed to understand which skills are in demand, which data-related roles offer higher salaries, and how job opportunities vary across different countries.

### Dashboard File

You can find the Power BI dashboard file here: [`Data Jobs Dashboard_2.0.pbix`](Data%20Jobs%20Dashboard_2.0.pbix).

## Skills Showcased

This project helped me practice and apply key Power BI features:

- **⚙️ Power Query ETL:** Cleaning, transforming, and preparing raw job-posting data for analysis.
- **📊 Data Visualization:** Using bar charts to compare in-demand skills and salaries across different job titles.
- **🧮 DAX Fundamentals:** Creating measures to calculate job counts, skills per job, and median salaries.
- **📈 KPI Cards:** Displaying important metrics such as job count, skills per job, median yearly salary, and median hourly salary.
- **🎛️ Interactive Filtering:** Using slicers to explore the data by job title, country, and selected measures.
- **🎨 Dashboard Design:** Organizing charts, KPI cards, and filters into a single-page layout for easy navigation and analysis.

## Dashboard Overview

This dashboard is designed as a **single-page report** that brings key insights about the data job market together in one place.

![Data Jobs Dashboard 2.0](/Images/Project2_image2.png)

The dashboard highlights four key metrics: **Job Count, Skills per Job, Median Yearly Salary, and Median Hourly Salary**.

It also includes visualizations to explore **the most in-demand skills in data-related roles** and **the highest-paying data job titles**. Interactive filters allow me to explore the results based on different job titles, countries, and measures.

## Conclusion

Building this dashboard gave me practical experience in using Power BI to turn raw job-posting data into meaningful insights. Through data transformation, DAX measures, visualizations, and interactive filtering, I created a dashboard that helps me explore the data job market and better understand the skills and salary trends relevant to my career interests.
