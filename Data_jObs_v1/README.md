# 📊 Data Jobs Dashboard

This project is an interactive **Power BI dashboard** that explores the data job market using job postings, salaries, locations, job types, and required skills.

The dashboard was created to help understand the data job market and identify the skills and roles that are relevant to aspiring data professionals.

## 🎯 Project Features

- 💼 **Job Market Overview** – Explore data-related job titles, salaries, and locations
- 💰 **Salary Analysis** – Compare salaries across different data roles
- 🔎 **Interactive Filtering** – Explore the data using slicers and filters
- 📊 **Data Visualization** – Present job-market trends through interactive charts and KPIs

## Skills Showcased

This project was a journey through key Power BI features. Here's a look at what I practiced and applied:

- **⚙️ Data Transformation (ETL) with Power Query:** Cleaned and transformed the raw job-posting data by changing data types, removing unnecessary columns, and cleaning text fields.

- **🧮 Data Analysis with DAX:** Created calculations and measures to analyze job counts, salaries, and other key metrics.

- **📊 Data Visualization:** Used **Line, Bar, Scatter, Donut, Treemap, and Map Charts** to analyze job trends, job counts, salaries, locations, job types, and other characteristics of data-related jobs.

- **🔢 KPI Cards & Job Statistics:** Used **Cards and a Matrix/Table** to present key metrics and provide detailed job statistics.

- **🗺️ Geospatial Analysis:** Used a **Map Chart** to visualize the geographical distribution of data-related jobs.

- **🎨 Dashboard Design:** Designed an interactive dashboard with a structured layout, visual hierarchy, and supporting shapes and elements to present the analysis clearly.

- **🖱️ Interactive Reporting:**
  - **Slicers:** To filter the dashboard by Job Title.
  - **Drill-Through:** To navigate from the main dashboard to a detailed view of a selected job title.
  - **Buttons & Bookmarks:** To create navigation between dashboard views.
 
## Dashboard Overview

*This report is split into two pages to provide both a high-level overview of the data job market and a detailed analysis of individual job titles.*

### Page 1: Data Jobs Dashboard

![Data Jobs Dashboard](/Images/Project1_image1.png)

This is the main dashboard providing a high-level view of the data job market. It includes key metrics and visualizations covering **job counts, salaries, job titles, locations, and skills**.

Users can interact with the dashboard using the **Job Title slicer** to explore the data and compare different roles.

The page includes **KPI cards, a line chart, bar chart, scatter chart, matrix, and interactive filtering** to provide an overview of the dataset.

### Page 2: Job Title Drillthrough

![Job Title Drillthrough](/Images/Project1_image2.png)

This page provides a detailed view of a selected **job title**. Users can drill through from the main dashboard to explore more specific information about that role.

The page includes **salary gauges, donut charts, a map, treemap, and bar chart** to analyze salary information, job characteristics, skills, locations, and other details associated with the selected job title.

## Conclusion

This dashboard demonstrates how Power BI can transform raw job-posting data into an interactive tool for exploring the **data job market**.

By combining data transformation, visualization, filtering, and drill-through functionality, the report allows users to move from a **high-level market overview to a detailed analysis of individual job titles**.
